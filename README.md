## 🏆 Featured Projects

### 🤖 JobReach AI — Fine-Tuned LLM for Outreach Generation

Fine-tuned **LLaMA 3.1-8B** using supervised fine-tuning and **LoRA** on NVIDIA A10G GPUs across **4,091 synthetic training samples**.

Built the complete inference path around the model, including training, checkpointing, evaluation, containerization, and serving through a **FastAPI endpoint**.

**Tech:** `LLaMA 3.1` · `LoRA` · `Hugging Face` · `PyTorch` · `FastAPI` · `Docker` · `NVIDIA A10G`

---

### ✈️ FlightSage — Multi-Agent AI Travel Strategist

Built a four-agent AI architecture separating:

* Intent parsing
* Deterministic flight search
* RAG retrieval over curated travel knowledge
* Response synthesis

An orchestrator coordinates the agents using **Claude and MCP**, while deterministic search logic stays outside the LLM path to reduce hallucination risk and make system behavior easier to test.

**Tech:** `Claude` · `MCP` · `ChromaDB` · `RAG` · `Python` · `Multi-Agent Systems`

---

### 🩺 Elderly Voice — Serverless Healthcare Reminder Platform

Built a serverless, event-driven AWS platform that delivers medication reminders through **phone calls, SMS, and email**.

The architecture uses managed AWS services to support reliable reminder processing while handling sensitive patient contact and medication information.

**Tech:** `AWS Lambda` · `Amazon Connect` · `Amazon Polly` · `DynamoDB` · `Event-Driven Architecture`
